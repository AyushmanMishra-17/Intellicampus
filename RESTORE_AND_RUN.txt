3. Allow Gradle sync to finish. Android Studio may download the Gradle distribution and dependencies.
4. If prompted, install the required Android SDK platform/build tools for compileSdk 36.
5. Connect an Android device with USB debugging enabled, or use an emulator, then press Run.
