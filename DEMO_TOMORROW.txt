INTELLICAMPUS - COLLEGE DEMO CHECKLIST

1. Android phone needs normal Internet access. The laptop does NOT need to run FreeLLMAPI.
2. Open Intellicampus and log in with the demo student account.
3. Confirm Dashboard -> Academics -> a subject -> Subject Details.
4. Open AI Tutor. If Render has been idle, allow the first request extra time while the free service wakes up.
5. Ask: "Explain Unit 1 of Computer Networks from my syllabus."
6. Verify that the answer is grounded in the student's current semester curriculum.
7. Try Quick Actions: Explain, Summarize, Quiz Me, Study Plan.
8. Open Chat History, reopen the conversation, start a New Chat, and test Delete conversation.
9. Open Profile and demonstrate batch, semester, academic year and role.
10. If demonstrating admin features, use a separate admin account and show Manage Academic Batches / Promote Semester.

AI BACKEND
----------
Hosted FreeLLMAPI:
https://intellicampus-ai-4huh.onrender.com/v1

The Android app defaults to this URL. Older local URLs are automatically migrated.
The FreeLLMAPI unified API key is entered in AI Tutor -> Settings and stored locally.
Do not put provider keys in the APK/source code.

BACKUP
------
If the hosted service is temporarily unavailable, the Android app can still show all
non-AI functionality. Do not switch back to the local LAN endpoint unless necessary.
